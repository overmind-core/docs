# Overmind docs

Documentation for the Overmind platform, published with [Mintlify](https://mintlify.com). Pages are MDX; `docs.json` holds the navigation.

## Development

```bash
bun install
bunx mint dev
```

Preview at `http://localhost:3000`. Run `bunx mint update` if the dev server misbehaves.

## Publishing

Pushing to the default branch deploys to production through the Mintlify GitHub app.
