Overmind ingests OpenTelemetry traces, scores them as they arrive, and turns them into datasets. Those datasets drive evals, the optimiser, and training.

The platform is open source. [overmind-core/overmind](https://github.com/overmind-core/overmind) holds the API, the Console, and the SDK. The same code runs hosted at overmindlab.ai and [self-hosted](/platform/self-hosting).

The Python SDK auto-instruments OpenAI, Anthropic, Gemini, Agno, and LangChain over OpenTelemetry. Any OTel exporter can POST to the same endpoint.

- [Live scoring](/agent-testing/trace-scoring): traces carved into task executions and judged against the capability's eval set
- [Datasets](/core/datasets): traces become eval and training data
- [Eval](/agent-testing/eval): variants measured against a baseline
- [Optimiser](/agent-testing/optimisers): candidates replayed in your repository; the winning diff is yours to apply
- [Training](/models/training) and [inference](/models/inference): fine-tune on Modal or Baseten; serve over an OpenAI-compatible API
- [MCP](/platform/mcp) and [CLI](/platform/cli): the same work from Cursor, Claude Code, OpenCode, or Codex

## Surfaces

| Surface | Hosted | Self-hosted default |
| --- | --- | --- |
| API | `https://api.overmindlab.ai` | `http://localhost:8000` |
| Console | `https://console.overmindlab.ai` | `http://localhost:5173` |
| MCP | `https://api.overmindlab.ai/api/mcp/` | `http://localhost:8000/api/mcp/` |

`ovr_` API keys: [Projects & administration](/platform/administration).
