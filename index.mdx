Tell your coding agent what you want to achieve. With Overmind connected through MCP, it can inspect your project, prepare datasets, investigate failures, compare models, run training and help connect the result to your application—all from the same conversation.

## Try it with your agent

[Connect Overmind](/how-to/connect), choose a project, then paste:

<AgentPrompt text="Use Overmind to prepare this ecommerce fraud dataset, train a decision model, and benchmark its results on held-out data: https://huggingface.co/datasets/apex0data/ecommerce-fraud-detection-synthetic-10k-sampl. Show me how it compares with a baseline and where it makes mistakes." />

Your agent takes the workflow from source data through preparation, training and benchmarking. You get a trained model and a comparison against a baseline on held-out examples. Follow [Train your first fraud model](/tutorials/first-dataset) for the full walkthrough. This request includes training and benchmark execution; the agent explains the proposed model and expected cost before launch.

## Ask for the outcome

| Your task | Example prompt | Guide |
| --- | --- | --- |
| Understand the application | “Map this repository's capabilities in Overmind.” | [Map an agent](/how-to/map-agent) |
| Find a failure pattern | “Investigate this capability's failures over the last 24 hours and show the evidence.” | [Investigate](/how-to/investigate) |
| Prepare data | “Turn these files into training examples and keep the preparation reproducible.” | [Prepare data](/how-to/prepare-data) |
| Compare results | “Compare these two models on the same evaluation set and explain the regressions.” | [Evaluate](/how-to/evaluate) |
| Improve the application | “Try two prompt changes against this eval set and show the best diff.” | [Optimise](/how-to/optimise) |
| Train a model | “Train a fraud decision model on this dataset.” | [Train](/how-to/train) |
| Follow a running job | “How is this training run doing, and what do its development checks show?” | [Monitor](/how-to/monitor-training) |
| Use the trained result | “Test this deployment and show me how to call it from my app.” | [Serve](/how-to/serve) |

A single request can span several steps. The agent carries the returned dataset, model and job identities forward, checks the results and reports the evidence. You do not need to construct each tool call yourself.

## Two ways to start

**Have data?** Start with files or a Hugging Face dataset and describe the prediction you want to make. Repository scans and capabilities are optional.

**Have an application?** Open its repository in your coding environment. Ask the agent to map it, add tracing, investigate recorded behaviour and evaluate a change.

MCP handles platform operations. Your agent also uses local files, the Overmind CLI and your application's tools. Initial login, secrets and client permissions still belong to their normal setup flows. The Console is available for visual inspection; it is not required for every step.
