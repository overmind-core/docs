## What is Overmind?

Overmind is a platform for improving production AI agents with their own data. It ingests OpenTelemetry traces from your agent, scores them with evaluators as they arrive, turns them into curated datasets, runs controlled eval experiments, proposes code changes as pull requests, and fine-tunes and serves models benchmarked against the model you run today.

Everything speaks standard protocols: trace ingest is OTLP/HTTP, the REST API is plain JSON over HTTPS, and model serving is OpenAI-compatible. Two endpoints matter:

| Surface | URL |
| --- | --- |
| API (ingest, REST, inference) | `https://api.overmindlab.ai` |
| Console | `https://console.overmindlab.ai` |

All programmatic access authenticates with a project-scoped API key (prefixed `ovr_`), sent as `X-Api-Key: <key>` or `Authorization: Bearer <key>`.

## How data flows

```flow
flow row
title: From your agent's process to a served fine-tune
A[Your agent | SDK or any OTel exporter] -> B[OTLP ingest | POST /api/v1/traces]
B -> C[Spans in Postgres | scored on arrival]
C -> D[Datasets | curated from traces]
D -> E[Eval runs | variants vs baseline]
E -> OP[Optimiser | code diffs, replayed + scored]
D -> T[Training | fine-tunes vs baseline]
T -> I[Inference | OpenAI-compatible API]
OP ~> A : winning diff lands as a PR
I ~> B : served model's calls are traced
```

There is no proprietary agent framework to adopt. The SDKs (`pip install overmind`, `npm install @overmind-lab/trace-sdk`) auto-instrument your existing OpenAI, Anthropic, and Gemini clients over OpenTelemetry, and any OTel SDK in any language can export to the same endpoint directly.

## Where to start

The [Quickstart](/quickstart) gets a first trace into the console in a few minutes: create an API key, initialise the SDK, make an LLM call. From there, [Observability](/core/observability) explains exactly what happens to a span after it leaves your process, and the [REST API](/platform/api) page lists every endpoint the console itself is built on.
