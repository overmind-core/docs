Overmind is a platform for building and improving AI applications and models. It brings together observability, data preparation, evaluation, model training and inference, so you can follow an improvement from the source data or observed failure through to a measured result.

You can start with an existing application or a dataset and a task. Connect Overmind to your coding agent, describe what you want to achieve, and work through the results in the same conversation.

## What you can do with Overmind

  <Card title="Prepare data" href="/how-to/prepare-data">Turn files, datasets or recorded traces into reproducible training and evaluation inputs.</Card>

These workflows connect: a failure found in a trace can become an evaluation example, and a prepared dataset can support training and a held-out comparison. You can also use each workflow on its own.

## How you use it

Your **coding agent** is where you describe the task. Through **MCP**, it discovers your Overmind projects and uses the platform's tools to prepare data, run evaluations, launch training and inspect results. It also writes code and uses the CLI for local files and repository work.

The **Overmind Console** gives you a visual view of the same project: datasets, traces, evaluations, training progress and deployments. Use it to inspect what the agent has created and follow running jobs.

A single prompt can cover a complete workflow. The agent works out the steps, carries the project context forward and brings back the results or decisions that need your input. Overmind retains the data, recipes and run records so you can inspect or continue the work later.

[Learn how the interfaces work together](/explanation/native-agent).

## Get started

1. **Connect your coding agent.** Paste the setup prompt below into your coding environment and follow the account and client setup steps.
2. **Choose a project and starting point.** Bring a dataset and describe the output you need, or open your application's repository to work from its code and traces.
3. **Ask for an outcome.** Request data preparation, an investigation, a model comparison or a training run. Your agent checks the proposed execution and expected cost before launching training.
