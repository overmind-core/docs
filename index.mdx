title: Introduction
---

Overmind improves production AI agents with their own data. It ingests OpenTelemetry traces, scores them as they arrive, turns them into curated datasets, and feeds three kinds of work: eval runs, optimisation runs that score code diffs in your repository, and training runs that produce models benchmarked against the one you ship today.

The platform is open source — [overmind-core/overmind](https://github.com/overmind-core/overmind) holds the API, the Console, and the SDK — and runs the same way hosted at overmindlab.ai or [self-hosted](/platform/self-hosting) with Docker Compose.

```flow
flow row
title: From your agent's process to a model you own
A[Your agent | SDK or any OTel exporter] -> B[OTLP ingest | POST /api/v1/traces]
B -> C[Spans in Postgres | scored per task execution]
C -> D[Datasets | curated from traces]
D -> E[Eval runs | variants vs baseline]
E -> OP[Optimiser | code diffs, replayed + scored]
D -> T[Training | trained models vs baseline]
T -> I[Inference | OpenAI-compatible API]
OP ~> A : winning diff applied locally
I ~> B : served model's calls are traced
```

Everything speaks standard protocols: OTLP/HTTP for ingest, REST JSON for the API, [MCP](/platform/mcp) for coding agents, OpenAI-compatible serving for models.

| Surface | Hosted | Self-hosted default |
| --- | --- | --- |
| API | `https://api.overmindlab.ai` | `http://localhost:8000` |
| Console | `https://console.overmindlab.ai` | `http://localhost:5173` |
| MCP | `https://api.overmindlab.ai/api/mcp/` | `http://localhost:8000/api/mcp/` |

Authenticate with an `ovr_` key as `X-Api-Key: <key>` or `Authorization: Bearer <key>`. There is no proprietary agent framework — the Python SDK auto-instruments OpenAI, Anthropic, Gemini, Agno, and LangChain over OpenTelemetry, and any OTel exporter can POST to the same endpoint.

Overmind gives you:

- **Live scoring** — every trace is carved into task executions and judged against the capability's eval set
- **Datasets from traffic** — convert traces into eval and training data, shaped by the dataset's own agent
- **Eval runs** — variants measured against a baseline with typed scores
- **Optimiser** — candidates generated and replayed in your repository by the CLI, scored on the platform, the winning diff on the candidate for you to apply
- **Training** — GPU runs on Modal or Baseten, loss curves, a benchmark against your production model
- **Inference** — OpenAI-compatible API for your trained models and frontier models
- **MCP and CLI** — the same workflows from Cursor, Claude Code, OpenCode, or Codex
