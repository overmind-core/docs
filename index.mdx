Overmind ingests OpenTelemetry traces, scores them as they arrive and turns them into datasets. Those datasets drive evals, optimisation runs and training runs, and every result is benchmarked against the agent you ship today.

Use the [hosted Console](https://console.overmindlab.ai) or [self-host](/platform/self-hosting) the same code with Docker Compose. The platform is AGPL-3.0 and the SDK is MIT; see [Licensing](/platform/licensing).

Everything speaks standard protocols: OTLP/HTTP for ingest, REST JSON for the API, [MCP](/platform/mcp) for coding agents and OpenAI-compatible serving for models. The Python SDK instruments OpenAI, Anthropic, Gemini, Agno and LangChain, and any OpenTelemetry exporter can send to the same endpoint.

What Overmind does:

- [Capability scan](/core/capabilities): your coding agent maps the repository into capabilities
- [Live scoring](/agent-testing/trace-scoring): every trace is carved into task executions and judged against the capability's eval set
- [Datasets](/core/datasets): traces and files become eval and training data, shaped by the dataset's own agent
- [Eval](/agent-testing/eval): variants measured against a baseline with typed scores
- [Optimiser](/agent-testing/optimisers): candidate code changes replayed in your repository and scored; the winning diff is yours to apply
- [Training](/models/training): fine-tuned models you own, trained on Modal from your data
- [Inference](/models/inference): an OpenAI-compatible API for your trained models and frontier models
- [MCP](/platform/mcp) and [CLI](/platform/cli): the same workflows from Cursor, Claude Code, OpenCode or Codex
