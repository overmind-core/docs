Each tutorial starts with one prompt and ends with something you can inspect. Your agent handles the MCP calls, local files and CLI commands. Start with the [quick-start instructions](https://console.overmindlab.ai/setup.md) and select a separate tutorial project. The [connection guide](/how-to/connect) explains how to verify access.

## Try it with your agent

<AgentPrompt text="Read https://console.overmindlab.ai/setup.md and follow the instructions to set up Overmind in my coding agent." />

Select your project when the agent shows the available choices. It carries that context through the conversation.

| Lesson | You ask for | You will inspect |
| --- | --- | --- |
| [Your first fraud model](/tutorials/first-dataset) | Prepare data, train a model and benchmark it | A trained model, baseline comparison and example mistakes |
| [Your first trace](/tutorials/first-trace) | Write and run one local tracing example | One trace with a tool call and its result |
| [Your first evaluation](/tutorials/first-evaluation) | Check recorded fraud labels | Valid answers and a deliberate vocabulary failure |

The fraud-model and evaluation tutorials use the same [fraud example dataset](/reference/example-dataset). The trace lesson uses a local function and needs no external data. You can take it independently.

The fraud-model tutorial includes training and benchmark inference. The trace example application makes no model calls, but enabled platform scoring may; the label-format evaluation does not train a model, although the platform may generate explanations for low scores. Your coding agent uses its own provider. Each tutorial states the work it starts.
