<Warning>
This page is **in development**. The TypeScript SDK (`@overmind-lab/trace-sdk`)
is being reworked to the capability-id identity model — its current release
still stamps the retired `overmind.agent.*` attributes, so its traces arrive
**unbound**. The documentation returns here with the updated release.
</Warning>

Until then:

- Instrument Python services with the [Python SDK](/tracing/sdk-python).
- Instrument Node.js services with any OpenTelemetry SDK and the
  [OTLP endpoint](/core/observability#the-otlp-endpoint), stamping
  `overmind.capability.id` as a resource attribute.
