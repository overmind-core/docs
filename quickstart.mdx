title: Quickstart
description: From zero to traces in the console — install the SDK, create an API key, make an LLM call.
---

<Steps>
  <Step title="Create a project and an API key">
    Sign up at [console.overmindlab.ai](https://console.overmindlab.ai). The onboarding wizard creates your first **project** — the scoping unit for agents, traces, datasets, runs, models, and keys.

    Create an API key from your project's page (**Projects → your project → API keys**) or from the Observability page's empty state. Keys are prefixed `ovr_`, are stored hashed, and are **shown once at creation** — copy it immediately. Optional expiry: 30/90/180 days, 1 year, or never.

    ```bash
    export OVERMIND_API_KEY="ovr_..."
    ```
  </Step>
  <Step title="Install the SDK">
    <CodeGroup>

    ```bash Python
    pip install overmind openai   # or: anthropic, google-genai, agno
    ```

    ```bash TypeScript
    npm install @overmind-lab/trace-sdk openai
    ```

    </CodeGroup>
  </Step>
  <Step title="Initialise tracing and make a call">
    Initialise once at process startup, before any LLM call. Your existing provider client code is instrumented in place — no import swaps, no proxy.

    <CodeGroup>

    ```python Python
    import overmind
    from openai import OpenAI

    overmind.init(
        service_name="my-service",
        environment="production",
        providers=["openai"],          # omit to auto-detect installed providers
        agent_name="Support Triage",   # attribute traces to an agent
    )

    client = OpenAI()
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "Classify this ticket: ..."}],
    )
    ```

    ```ts TypeScript
    import { OpenAI } from "openai";
    import { OvermindClient } from "@overmind-lab/trace-sdk";

    const overmind = new OvermindClient({
      apiKey: process.env.OVERMIND_API_KEY!,
      appName: "my-service",
      agentName: "Support Triage", // attribute traces to an agent
    });

    overmind.initTracing({ enabledProviders: { openai: OpenAI } });

    const openai = new OpenAI();
    const response = await openai.chat.completions.create({
      model: "gpt-4o-mini",
      messages: [{ role: "user", content: "Classify this ticket: ..." }],
    });

    await overmind.shutdown(); // flush before a short-lived process exits
    ```

    </CodeGroup>

    Spans export over OTLP/HTTP to `https://api.overmindlab.ai/api/v1/traces` and appear in **Observability** in near real time.
  </Step>
  <Step title="Not using Python or Node? Export OTLP directly">
    The ingest endpoint accepts standard OTLP/HTTP **protobuf** from any OpenTelemetry SDK. Point your exporter at the API base URL (the exporter appends `/v1/traces`) and pass your key as a header:

    ```bash
    export OTEL_EXPORTER_OTLP_ENDPOINT="https://api.overmindlab.ai"
    export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"   # JSON and gRPC are not accepted
    export OTEL_EXPORTER_OTLP_HEADERS="x-api-key=ovr_..."
    ```

    See [Observability](/core/observability#the-otlp-endpoint) for the attribute conventions the ingest pipeline reads.
  </Step>
  <Step title="Check the console">
    Open **Observability**. Each row is a root span; click one for the span tree, timeline, and full model-call transcripts.

    <Frame caption="The trace list: duration, tokens, cost, model, status, scores, and agent per root trace.">
      <img src="/images/platform/tracing-list.png" alt="Observability trace list in the Overmind console" />
    </Frame>

    The **Get started** page in the console tracks the same setup as a live checklist: project → repository scan → API key → tracing → dataset.
  </Step>
</Steps>
