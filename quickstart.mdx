<Tip>
No account yet? Open [console.overmindlab.ai/demo](https://console.overmindlab.ai/demo) to scan a public GitHub repository as a guest; `?repo=https://github.com/owner/repo` prefills the form. The guest session starts with the scan. A guest workspace holds one scan of a repository up to 200 MB, is read-only otherwise, and is deleted after 7 days. Creating an account from inside the workspace moves it to that account.
</Tip>

<Steps>
  <Step title="Create a project and an API key">
    Sign up at [console.overmindlab.ai](https://console.overmindlab.ai). The onboarding wizard creates your first **project** — the scoping unit for capabilities, traces, datasets, runs, models, and keys.

    Create an API key from your project's page (**Projects → your project → API keys**) or from the Observability page's empty state. Keys are prefixed `ovr_`, stored hashed, and **shown once at creation** — copy the key immediately. Optional expiry: 30/90/180 days, 1 year, or never.

    ```bash
    export OVERMIND_API_KEY="ovr_..."
    ```
  </Step>
  <Step title="Paste the setup prompt into your coding agent">
    Open your app in Cursor, Claude Code, or another coding agent and paste this prompt (same text as the Observability empty state):

    ```text
    Install the Overmind AI skill from github.com/overmind-core/overmind and use it to add tracing to this application with Overmind following best practices.
    ```

    The skill installs the SDK, initialises tracing, and instruments your LLM providers. Keep `OVERMIND_API_KEY` in the environment (or a `.env` file) so the agent can run and verify without pasting the key into chat.

    Prefer to wire it by hand? See the [Python SDK](/tracing/sdk-python) or [TypeScript SDK](/tracing/sdk-typescript).
  </Step>
  <Step title="Not using Python or Node? Export OTLP directly">
    The ingest endpoint accepts standard OTLP/HTTP **protobuf** from any OpenTelemetry SDK. Point your exporter at the API base URL (the exporter appends `/v1/traces`) and pass your key as a header:

    ```bash
    export OTEL_EXPORTER_OTLP_ENDPOINT="https://api.overmindlab.ai"
    export OTEL_EXPORTER_OTLP_PROTOCOL="http/protobuf"   # JSON and gRPC are not accepted
    export OTEL_EXPORTER_OTLP_HEADERS="x-api-key=ovr_..."
    ```

    See [Observability](/core/observability#the-otlp-endpoint) for the attribute conventions the ingest pipeline reads.
  </Step>
  <Step title="Check the console">
    Open **Observability**. The default **Task executions** view shows one row per scored unit of work; switch to **Root traces** for one row per trace. Click a row for the span tree, timeline, full model-call transcripts, and the verdicts with their reasoning.

    <Frame caption="The trace list: duration, tokens, cost, model, status, scores, and capability per root trace.">
      <img src="/images/platform/tracing-list.png" alt="Observability trace list in the Overmind console" />
    </Frame>

    The **Get started** page in the console tracks the same setup as a live checklist: project → repository scan → API key → tracing → dataset.
  </Step>
</Steps>
