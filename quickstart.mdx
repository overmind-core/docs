<Card title="Open the Console" href="https://console.overmindlab.ai">
  Sign up or sign in at console.overmindlab.ai.
</Card>

Self-host: [Self-hosting](/platform/self-hosting).

<Tabs>
  <Tab title="Coding agent">
    <Steps>
      <Step title="Copy the onboarding prompt">
        The **Agent** page opens empty. Pick **Cursor**, **Claude Code**, **OpenCode**, or **Codex**, then **Copy onboarding prompt**. The prompt carries a temporary account-scoped bootstrap key — paste it only into a local coding agent.
      </Step>
      <Step title="Paste it at the repo root">
        Paste the prompt into Cursor, Claude Code, OpenCode, or Codex with the repository root as the workspace. Reload the IDE when it finishes, then use `/overmind` commands.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Manual">
    <Steps>
      <Step title="Create a project">
        In the Console, create a project. A project scopes capabilities, traces, datasets, runs, models, and keys.
      </Step>
      <Step title="Create a project-scoped key">
        **Projects → your project → API keys**. Copy the `ovr_` key once.
      </Step>
      <Step title="Install and scan">
        ```bash
        pip install overmind
        export OVERMIND_API_KEY=ovr_…
        overmind init --ide cursor   # optional: skill, /overmind commands, MCP entry
        overmind scan
        overmind scan finalize
        ```

        Self-hosted: `export OVERMIND_API_URL=http://localhost:8000` and `overmind init --ide cursor --env local`.
      </Step>
      <Step title="Author cards and push">
        Fill `.overmind/cards/<key>.json`, then `overmind scan push`. What each step writes: [Agent & Capabilities](/core/capabilities#the-scan). Tracing: [Python SDK](/tracing/sdk-python). Raw OTLP: [Observability](/core/observability). Flags: [CLI](/platform/cli).
      </Step>
    </Steps>
  </Tab>
</Tabs>

After reload, Cursor and Claude Code get `/overmind onboard`, `/overmind setup`, `/overmind ensure-tracing`, `/overmind dataset`, `/overmind finetune`, `/overmind optimise`, and `/overmind backtest`. OpenCode and Codex get the skill and MCP entry; describe the goal instead. [CLI](/platform/cli) · [MCP](/platform/mcp).

Deployed processes need `OVERMIND_API_KEY` in their runtime. Local runs reuse `.overmind/credentials.toml` after `overmind scan push`.

## In the Console

Open **Observability**. **Task executions** is one row per scored unit; **Root traces** is one row per trace; **Sessions** groups traces by session.

<Frame caption="Task executions: one row per scored unit, with the task it bound to and its execution score.">
  <img src="/images/platform/observability-executions.jpg" alt="Observability task executions view in the Overmind console" />
</Frame>

The **Agent** page fills in as each step lands: capabilities after the first push, traffic and scores once traces arrive, **Confirmed** on a capability once a trace binds to it.
