Deployed fine-tunes are served behind an OpenAI-compatible API at `https://api.overmindlab.ai/api/v1`, authenticated with the same `ovr_` key you use everywhere else. Frontier models are callable through the same gateway, so comparing your fine-tune against a hosted model is a change of the `model` field, not a second integration.

## Deployment lifecycle

Deployment starts automatically when a training experiment succeeds. A model moves through **Queued → Quantizing → Deploying → Warming → Ready**, and only Ready models accept traffic; failed deployments can be retried without retraining. Deleting a model is irreversible and removes the weights — download them first if in doubt.

## Calling your model

Use any OpenAI SDK pointed at the base URL, with your model's reference (copyable from the models table) as the model name:

<CodeGroup>

```python Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
    base_url="https://api.overmindlab.ai/api/v1",
    api_key="ovr_your_key_here",
)

response = client.chat.completions.create(
    model="ft-9635f347-qwen2-5-0-5b-instruct",
    messages=[{"role": "user", "content": "Classify this ticket: ..."}],
    stream=True,
)
for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
```

```python Python (overmind SDK)
import overmind

client = overmind.Client()  # reads OVERMIND_API_KEY / OVERMIND_API_URL

response = client.chat.completions.create(
    model="ft-9635f347-qwen2-5-0-5b-instruct",
    messages=[{"role": "user", "content": "Classify this ticket: ..."}],
)
print(response.choices[0].message.content)

for m in client.models.list():   # also: client.models.get(id), client.models.delete(id)
    print(m)
```

```ts TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.overmindlab.ai/api/v1",
  apiKey: process.env.OVERMIND_API_KEY,
});

const response = await client.chat.completions.create({
  model: "ft-9635f347-qwen2-5-0-5b-instruct",
  messages: [{ role: "user", content: "Classify this ticket: ..." }],
});
console.log(response.choices[0].message.content);
```

```bash curl
curl https://api.overmindlab.ai/api/v1/chat/completions \
  -H "Authorization: Bearer ovr_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ft-9635f347-qwen2-5-0-5b-instruct",
    "messages": [{"role": "user", "content": "Classify this ticket: ..."}]
  }'
```

### Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/api/v1/chat/completions` | Generate a completion; streaming via `stream: true` |
| `GET` | `/api/v1/models` | List deployed fine-tunes and callable frontier models. Filter with `?status=` — `ready` (default), `queued`, `deploying`, `warming`, `failed`, `deleting`, `deleted`, or `all` |
| `GET` | `/api/v1/models/{model_id}` | One model's status and metadata (any status) |
| `DELETE` | `/api/v1/models/{model_id}` | Stop serving and remove a fine-tuned model's weights |

The gateway routes by model ID: your `ft-...` references go to Overmind's serving infrastructure; frontier IDs (`openai/...`, `anthropic/...`, `meta-llama/...`, `qwen/...`) are proxied to their providers. Every call is metered and appears in the model's usage metrics.

### Errors worth handling

| Code | Meaning | What to do |
| --- | --- | --- |
| `402` | Insufficient credits | Top up under Settings |
| `404` | Model not found, or not in this key's project | Check the model reference and the key |
| `429` | Upstream rate limit (frontier models) | Standard SDK retry logic works — the status is passed through |
| `502` | Transient backend/provider error | Retry with backoff |
| `503` | Model not ready — still deploying or warming | Poll `GET /api/v1/models/{id}` and retry |

## Closing the loop

Point your traced application at a deployed model and its calls flow back into [Observability](/core/observability) like any other provider's — tokens, latency, and live eval scores included. A model switch is therefore measurable in production with the same evaluators that justified it offline. For the switch itself, the **Model PR** from the [training job](/models/training#after-training) edits your repository and opens the pull request.
